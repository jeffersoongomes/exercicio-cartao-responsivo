# 📱 Desafio Prático - Cartão de Produto Responsivo

Projeto desenvolvido para exercitar conceitos avançados de **Design Responsivo**, **Media Queries** e **Animações CSS**.

🎮 **[CLIQUE AQUI PARA VER A PÁGINA AO VIVO](https://jeffersoongomes.github.io/exercicio-cartao-responsivo/)**

---

## 📌 Requisitos Atendidos
- **Telas Pequenas (até 600px):** Disposição vertical (1 coluna) ocupando largura total.
- **Telas Médias (601px a 992px):** Exibição de 2 cartões por linha.
- **Telas Grandes (acima de 993px):** Exibição de 3 cartões por linha.
- **Imagens Responsivas:** Ajuste sem distorção via `object-fit: cover`.
- **Tipografia Flutuante:** Uso de unidades relativas (`rem`).
- **Animações:** Transições suaves no efeito `hover` dos cartões e botões.

---

## 🚀 Tecnologias Utilizadas
- HTML5
- CSS3 (Grid Layout, Flexbox e Media Queries)
- GitHub Pages
